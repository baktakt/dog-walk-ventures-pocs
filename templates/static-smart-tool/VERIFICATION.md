- [ ] No secrets in files.

## Manual checks

- [ ] App opens locally.
- [ ] Skip link works.

- [ ] Focus states are visible.
- [ ] Sample data loads.
- [ ] Primary action creates output.
- [ ] Copy/export actions work.
- [ ] Mobile width is usable.
- [ ] Trust warning is visible.
- [ ] Output is clearly marked draft/reviewable.

## Deployment checks

- [ ] Vercel production URL returns HTTP 200.
- [ ] Page title is correct.
- [ ] README includes live URL.
- [ ] DEPLOYMENT.md records project details.
