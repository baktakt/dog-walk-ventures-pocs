# [POC Name] Design Notes

## CDO review target

This POC should feel like a calm, practical Dog Walk Ventures workshop utility.

## Required template sections

- Header with Dog Walk Ventures identity.
- Promise card.
- Input workbench.
- Processing/status area.
- Structured output cards.
- Human review/trust panel.
- Feedback prompt.

## Mobile requirements

- Single-column layout below 900px.
- Large tap targets.
- No horizontal scrolling.
- Sticky action bar only if it does not obscure content.

## Accessibility requirements

- All inputs have labels.
- Buttons have clear text.
- Focus states are visible.
- Output updates are announced.
- Color is supported by text labels.

## Copy rules

Use plain verbs:

- Create
- Extract
- Compare
- Summarize
- Export
- Copy

Avoid hype:

- AI-powered platform
- revolutionize
- autonomous intelligence layer
- disrupt
