# Dog Walk Ventures Design System

This folder documents the shared design system for all Dog Walk Ventures smart-tool POCs.

## Owner

The **CDO agent** owns this system.

CDO = Chief Design Officer agent. Its role is to keep every POC recognizably Dog Walk Ventures: useful, humane, calm, trustworthy, and fast.

## Agent entry points

- `DESIGN.md` — formal token spec for coding/design agents
- `cdo-agent-brief.md` — role, responsibilities, review checklist
- `poc-ui-conventions.md` — layout and interaction rules for smart-tool POCs
- `app-shell.md` — common page/application structure

## Design thesis

Dog Walk Ventures tools should feel like:

> A calm, competent workshop utility: small, bright, humane, practical.

Not like:

- enterprise bloat
- VC SaaS theater
- generic AI chat wrappers
- dark dashboards
- growth-hacked consumer apps

## Core motto

> Small tools. Real pain. Human upside.
