# Design notes

## Product feel

A calm public-works utility: practical, readable, and careful about trust boundaries.

## Mobile-first choices

- large touch targets
- single-column layout on phones
- paste-first input
- clear output cards before detailed table

## Trust posture

The UI repeats that this is a draft checklist only. It avoids authoritative compliance language and reminds users to verify against the actual permit and official reporting system.

## Accessibility

- semantic header/main/footer
- skip link
- labels for textarea/date input
- visible focus states
- `aria-live` output areas
- reduced-motion handling
